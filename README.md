# LEGACY 9 · 웹 배포본

**바로 플레이: https://xinker-kim.github.io/legacy9-play/**

이 저장소는 KBO 구단 운영 시뮬레이션 **LEGACY 9**의 정적 빌드 산출물만 담습니다.
소스 코드와 개발 이력은 비공개 저장소 `XinKer-Kim/legacy9`에 있으며, 여기에는
`npm run build`로 만들어진 파일과 공개 에셋만 올라갑니다.

- 스마트폰 세로 화면을 기준으로 만들어졌습니다.
- 저장은 브라우저(IndexedDB)에 남습니다. 서버로 전송되는 자료는 없습니다.
- 이 저장소에 직접 커밋하지 마세요. 소스 저장소에서 `node scripts/publish-pages.mjs`로 갱신합니다.

## 클로즈베타 안내

**의견 보내기:** 게임 안의 ☰ 메뉴나 **설정 · 저장** 화면에 링크가 있습니다. 막히거나 이상해 보이는
화면을 만나면 설정에서 **파일 내려받기**로 저장을 받아 함께 올려 주세요. 그 파일이 있어야 같은 상황을
다시 열어 볼 수 있습니다.

**아직 측정하지 않은 능력이 있습니다.** 능력치는 2026 시즌 공개 기록에서 산출하는데, 수비와 투수
운영은 공개 기록에 해당 지표가 없습니다. 지금은 **모든 선수의 수비·운영이 미측정**이고 투수 구속도
일부만 채워져 있어, 그 자리는 등급 대신 **—**로 표시합니다. 밸런스가 무너진 것이 아니라 아직 값을
정하지 않은 것입니다. 경기에는 같은 급의 대체값을 씁니다. 원시 기록 수집이 끝나는 대로 채워집니다.

**저장이 사라질 수 있습니다.** 브라우저 저장이라 방문 기록을 지우거나 다른 기기·다른 브라우저로 열면
이어지지 않습니다. 베타 중 업데이트가 나가면 진행 중인 게임을 새로 시작해야 할 수 있으니, 남기고 싶은
시즌은 **파일 내려받기**로 받아 두세요.

**상점과 광고는 준비 중입니다.** 결제·광고는 연결되어 있지 않고, 상점에서 살 수 있는 것도 없습니다.
