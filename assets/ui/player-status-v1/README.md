# 선수 상태 아이콘 — 얼굴 / 화살표

컨디션 얼굴 5종, 의욕 화살표 5종. SVG 10개, 투명 PNG 30개(64·128·256px).
앞선 이미지 시안의 둥근 얼굴·광택 스타일을 참고해 새로 그린 벡터 에셋이다. 원본 이미지를 잘라낸 파일은 아니다.

## 배치
ZIP을 `D:\야구게임 개발`에 풀면 `public/assets/ui/player-status-v1/`에 들어간다.
이 패키지는 전달용으로 제작되었으며 사용자 PC D 드라이브에 직접 설치된 것은 아니다.
Vite 등의 public 정적 파일 방식 기준 권장 경로다. 실제 프로젝트 구조는 확인하지 못했으므로 다른 엔진은 에셋 디렉터리로 옮겨 사용한다.

## 단계
5 최상 빨강 #F04452 ↑ / 4 좋음 주황 #F58A35 ↗ / 3 보통 노랑 #EBCB47 → / 2 나쁨 파랑 #438FE5 ↘ / 1 최악 보라 #9661CC ↓
화살표는 현재 의욕 단계이며, 전일 대비 상승·하락 추세가 아니다. 툴팁에 의욕과 단계명을 함께 표시한다.
기존 게임 수치에서 5단계로 변환하는 임계값과 효과는 변경하지 않는다.

## 사용
웹 UI에는 SVG 사용 권장. PNG가 필요한 렌더러에는 표시 크기 대비 2배 이상의 PNG를 사용한다.
배경·글자·타일이 없는 독립 아이콘으로 64×64 좌표에 통일했다.
16px~32px 권장 표시 크기는 preview.html에서 밝고 어두운 배경 모두 비교할 수 있다.

```html
<img src="/assets/ui/player-status-v1/svg/condition-5-best.svg" width="24" height="24" alt="컨디션 최상" title="컨디션: 최상">
<img src="/assets/ui/player-status-v1/svg/motivation-3-normal.svg" width="24" height="24" alt="의욕 보통" title="의욕: 보통">
```

manifest.json의 경로는 해당 파일 기준 상대 경로다. level은 5가 최고이고 1이 최저다.
외부 폰트·이미지·스크립트 의존성이 없는 SVG다. 원본 그림은 유지하며 새 에셋을 별도 생성했다.
