Overview

실제 구현

상세 화면에 확정한 기간을 실행 버튼에 연결했다. 갱신 견적은 실제 계약 시작 연도 전체를 사용하고, 제안 비율 변경 즉시 계약금·총 약정·추가 연봉을 같은 함수로 계산한다. 기존 i 도움말에 가정과 대체 경로를 설명한다.

장기 계약의 이점은 연봉 유지·재계약 횟수 감소이고 대가는 중도 교체 때 남은 연봉 정산이다. 계약하지 않으면 기본 인력이 맡는다. 저장이 실패하면 이전 기간·계약·현금을 유지한다.
