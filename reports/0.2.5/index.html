Overview

같은 정액 캠프에서 성장 가능한 선수를 임의로 20명만 추천하던 동작을 고쳤다. 새 캠프나 보너스를 추가하지 않았다. 원본 KT 40명 중 실제 성장 가능한 36명을 추천한다.

Before · After

수정 전 성장 우선은 20명에서 멈췄다. 수정 후에는 기존 나이·POT 우선순위를 유지하면서 실제 효과가 있는 선수를 최대 40명까지 채운다. 40명 전원 참가 중 4명은 POT 상한으로 성장하지 않아 추천에서 제외된다. 직접 20명만 선택하는 기능은 유지한다.

실제 구현

선택 전 정액 요금과 인원을 줄여도 개인 효과가 늘지 않는다는 점을 표시했다. 자세한 성장 순서·피로·상한 설명은 기존 i 도움말로 옮겼다. 저장 실패 때 선택과 자금·능력치를 유지하며 성공 후에만 효과와 영수증을 적용한다. 같은 해 중복 정산과 재접속도 검사했다. 참가 목록만 스크롤하고 비용·확정 버튼은 처음부터 하단 메뉴 위에 보이도록 수정했다. 자동 스크롤 이전의 버튼 좌표와 실제 hit-test를 검사한다. 수정 전 390px 화면의 기존 가로 넘침을 재현했고 참가 인원·추천 버튼을 줄바꿈하여 수정 후 네 크기에서 넘침 없이 조작하도록 고쳤다.

경제 · BM

오키나와 캠프는 참가자 수와 무관하게 1.6억 원이다. 20명은 능력치 총합 +6.4, 40명 전원(36명 효과)은 +11.52이다. 이는 개인 OVR +11.52가 아니라 선수별 6능력치 증가분의 합이다. 참가자의 성장량을 서로 나누지 않는다. 신규 가격·유지비·유료 상품·실결제는 도입하지 않았다.

밸런스 · 실측 범위

동일한 실제 원본 로스터·시드·스태프·훈련·인공 완성 시설의 짝비교다. 시작 잔액은 기본 자금과 이미 받은 수입을 포함한 80억 원이며 시설 건설비는 지출하지 않았다. 3시드×2참가 정책×72경기 1시즌, 리그 정규경기 총 2,160경기를 공통 코어로 진행했다. 0.2.4의 90시즌을 재실행한 것으로 합산하지 않았다.

피로 · 회복 · AI

즉시 피로 합계는 20명 +60, 36명 효과 +108이다. 공통 참가자 20명의 성장·피로 효과는 정확히 동일하다. 추가 피로를 피하고 싶은 선수를 직접 제외하는 선택은 유효하다. 이번 3시드에서는 7일 후 팀 피로 합계가 두 정책에서 같았지만 선수별 상태와 성적까지 같다는 뜻은 아니다. AI 선수에는 캠프 보너스를 새로 주지 않았고 정산 직후 AI 상태·난수 불변, 실제 시즌의 공통 경기·성장 규칙을 확인했다.

기술 변경

camp-3 효과·요금·POT 및 능력치 99 상한·camp-1/2 영수증 호환을 유지했다. 추천의 20명 제한만 제거하고 추천 동점·영수증 canonical 정렬은 코드포인트 비교로 통일했다. 저장 스키마와 PS 기준선은 바꾸지 않았다. 추천 36명과 전원 40명의 실제 구단 상태·난수·원장 동일성도 회귀 검사한다.

검증

Node 24.11.1의 타입 검사와 432개 검사, 신규 6시즌 실측, Chromium 344×882·360×640·390×844·1280×844 실제 조작을 수행했다. 수동 20명 동일 요금·19명 차단·도움말·저장 실패·재시도·한 번 지출·재접속을 확인했다. 테스트의 실제 시즌/다음 해 경계와 기존 캠프 영수증 호환도 유지했다. 보고서의 TAP/spec 검사 요약 파서는 실패·누락·건너뜀을 성공으로 바꾸지 않는다. 최종 빌드·독립 HTML·인계의 기계 판독 증거는 validation.json과 report-verification.json에 보관한다.

남은 문제

추천 36명이 항상 승리나 부상 감소를 보장하지 않는다. 표의 승수 차이는 표본 3개 관찰이지 기대 승률 효과가 아니다. 사용자 웹 샌드박스에서는 네트워크와 Chromium 탐색이 관리자 정책에 차단되어 브라우저·빌드는 비공개 CI에서 검증한다. 별도의 웹 Node 22 보조 실측 6시즌은 최종 표와 구분한다. 실물 모바일·Safari·Windows·전체 구단 장기 시즌은 미검증이며 빌드 큰 청크 경고는 남아 있다.
